# Contributing

Thanks for helping improve Auralyn Click.

## Development setup

```bash
./scripts/run-dev.sh
```

## Before opening a pull request

- keep Linux/Ubuntu compatibility in mind
- do not add telemetry or hidden network behavior
- do not add anti-cheat bypasses or stealth features
- keep F8 as a stop-only emergency shortcut
- keep settings backward-compatible when practical
- run `python3 -m compileall -q src auralyn-click-control.py`

Please describe what changed and how you tested it in the pull request.
